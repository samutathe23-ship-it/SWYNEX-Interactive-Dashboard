# SWYNEX Interactive Dashboard

## Project Overview
An interactive Power BI dashboard created using the Titanic dataset as part of the SWYNEX Data Analyst Internship – Task 3.

## Dashboard Features
- KPI Cards: Total Passengers, Survivors, Survival Rate, and Average Fare
- Survival Rate by Gender
- Survival Rate by Passenger Class
- Passenger Age Distribution
- Passenger Fare Distribution
- Interactive filters for Sex, Pclass, and Embarked

## Tools Used
- Microsoft Power BI Desktop
- Titanic Dataset
- DAX (Data Analysis Expressions)

## Key Results
- Total Passengers: 891
- Survivors: 342
- Overall Survival Rate: 38.4%
- Average Fare: 32.20

## Project File
The Power BI dashboard is available in this repository as `SWYNEX_Interactive_Dashboard.pbix`.
